灰烬王冠 · 第二版（Windows x64）
================================

课程内容
- 共7章、140道短题，每章20题。
- 完成当前章20题后自动解锁下一章。
- 章节地图提供“上一章”和“下一章”主动切换按钮。
- 每题包含故事、目标、3个提示、代码编辑器、真实编译与判题。

快速编译
- 游戏启动后会在后台预热1个主Clang worker和2个备用worker。
- 预热完成后，短题的连续编译通常可在约1秒内完成；实际速度取决于电脑性能。
- 每个worker完成一次学员编译后会被销毁并在后台补充，保留隔离边界。

AI导师（可选）
- 在设置中填写OpenAI兼容API URL、模型名称和可选API Key，并点击“测试连接”。
- API URL可填写到 /v1，也可以填写完整的 /chat/completions 地址。
- 同一道题连续正式提交错误3次后，AI导师按钮才会解锁。
- AI导师每章只能成功使用1次，使用前会再次确认。
- AI只解释当前题目、代码、编译信息和输出，不负责通关判定，也不会直接给出完整答案。
- API Key单独保存在 data\save\ai-settings.json，不会进入旅程导出JSON。
- 使用AI导师时，当前题目、代码、编译信息和输出会发送到用户自己配置的API服务。

运行方式
1. 请保留“GrayCrown.exe”和“data”文件夹在同一目录。
2. 双击“GrayCrown.exe”。程序会启动本机服务并自动打开默认浏览器。
3. 学习结束后，关闭启动器的黑色窗口即可完全退出。

无需安装
- 无需安装 Python、Node.js、Rust、C 编译器或其他运行库。
- Clang 编译器和 WebAssembly 沙箱已经随 data 文件夹离线携带。
- 第一次编译通常比后续编译慢几秒，这是浏览器加载离线编译器造成的。

本地存档
- 存档位置：data\save\progress.json
- 每次覆盖前会保留一份：data\save\progress.json.bak
- 设置页仍可手动导出/导入 JSON 备份。
- 搬家时请连同整个文件夹一起复制，或提前导出存档。

正确答案道具
- 每章20题提供3枚“真知水晶”，数量显示在游戏右上角。
- 点击“查看正确答案”后，会先出现确认弹窗；确认才会消耗水晶。
- 已经解锁过的题目可以重复查看，不会重复扣除。

安全边界
- 网页只监听 127.0.0.1，不会开放到局域网。
- 学员代码在 WebAssembly worker 沙箱内运行，不映射电脑文件夹，也不授予网络访问。
- 单次运行超过 4 秒会被强制终止，防止死循环长期占用。

命令行选项（可选）
- --no-open       启动后不自动打开浏览器
- --port 42617    使用指定的本机端口（默认自动选择空闲端口）
- --data-dir 路径 使用另一个 data 目录

系统要求
- Windows 10/11 x64
- 支持 SharedArrayBuffer 和 WebAssembly 的现代浏览器（推荐最新版 Edge 或 Chrome）
